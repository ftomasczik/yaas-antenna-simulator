# Antenna Simulator

Simulador de antenas de escritorio basado en Python y NEC2++.

## Estado

Proyecto en etapa inicial de desarrollo.

## Objetivos principales

- Modelar antenas mediante una interfaz gráfica.
- Ejecutar simulaciones con NEC2++.
- Mantener una interfaz de línea de comandos.
- Importar mediciones de NanoVNA.
- Leer y exportar archivos NEC.
- Comparar simulaciones con mediciones reales.

## Requisitos de desarrollo

- Windows de 64 bits
- Python 3.13
- Git
- Visual C++ Build Tools
