# AntSim 0.1.0

- Fecha: 2026-09-26
- Rama: `release/0.1.0`

## Alcance del hito

AntSim 0.1.0 es el primer hito funcional del proyecto: un simulador de
antenas utilizable de punta a punta desde la línea de comandos, sobre
PyNEC/NEC2++, capaz de simular, comparar contra mediciones reales e
importar proyectos de otra herramienta (MMANA-GAL). Ver
`CHANGELOG.md` para el detalle completo de lo agregado en este hito.

## Requisitos de Windows

- Windows x64.
- Para desarrollo: Python 3.13, Git, Visual C++ Build Tools y
  PowerShell.
- Para usar solo el ejecutable (`dist\antsim.exe`): ningún requisito
  adicional; PyInstaller empaqueta el intérprete de Python y las
  dependencias necesarias.

## Instalación de desarrollo

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
antsim doctor
```

## Uso del ejecutable

```powershell
.\scripts\build_windows.ps1
```

Genera `dist\antsim.exe` y ejecuta la suite de pruebas y las pruebas
de humo del propio ejecutable (diagnóstico, simulación, barridos,
proyectos, exportación CSV y NEC, comparación con mediciones e
importación MMANA-GAL, en español e inglés).

## Comandos principales

Diagnóstico del entorno:

```powershell
antsim doctor
```

Simular un proyecto:

```powershell
antsim simulate .\examples\dipole-20m.antsim
```

Barrido de un proyecto, con exportación a CSV:

```powershell
antsim sweep .\examples\dipole-20m.antsim --output .\barrido.csv
```

Exportar un proyecto a NEC:

```powershell
antsim export-nec .\examples\dipole-20m.antsim .\dipole-20m.nec
```

Comparar un proyecto con una medición Touchstone:

```powershell
antsim compare .\examples\dipole-20m.antsim .\medicion.s1p `
    --reference-impedance 50
```

Importar un proyecto MMANA-GAL:

```powershell
antsim import-mmana .\antena.maa .\antena.antsim `
    --sweep-start 13.5 --sweep-stop 15.5 `
    --sweep-points 81 --swr-limit 2.0
```

Ver `README.md` para el resto de los comandos y sus opciones.

## Formatos soportados

- Proyectos `.antsim` (JSON versionado, esquema actual: 1).
- Exportación NEC (tarjetas `CM`, `CE`, `GW`, `GE`, `EX`, `FR`, `EN`),
  validada externamente con 4nec2 5.9.3.
- Exportación de barridos a CSV.
- Lectura de mediciones Touchstone de un puerto (`.s1p`), formatos
  `RI`, `MA` y `DB`, en Hz/kHz/MHz/GHz.
- Importación de proyectos MMANA-GAL (`.maa`), subconjunto compatible
  documentado en `docs/phases/phase-6-mmana-import.md`.

## Limitaciones

- Solo se modelan conductores rectos, en espacio libre, con una única
  fuente de tensión y sin cargas concentradas.
- No hay interfaz gráfica ni generación de gráficos.
- Solo se importan archivos Touchstone de un puerto (`.s1p`); no se
  admite `.s2p` ni otros formatos multipuerto.
- La importación MMANA-GAL es estricta: un archivo fuera del
  subconjunto compatible se rechaza con un error, nunca se importa
  parcialmente ni de forma aproximada más allá de lo documentado.
- La segmentación de MMANA-GAL (tapering) se convierte a una
  densidad NEC uniforme (`lambda/160`, ver ADR 0007); esta política
  no reproduce el mallado original de MMANA-GAL.
- Pueden existir diferencias esperables entre los resultados de
  MININEC (usado internamente por MMANA-GAL) y NEC2++ (usado por
  AntSim), incluso para geometrías equivalentes.
- El formato `.antsim` dispone actualmente de una única versión de
  esquema.

## Validaciones realizadas

- Suite automatizada completa: 409 pruebas (incluye integración con
  PyNEC), ejecutada antes de este hito y de nuevo como parte de la
  construcción del ejecutable.
- Exportación NEC de frecuencia única, validada externamente con
  4nec2 5.9.3 (ver `docs/validation/nec-export-4nec2.md`): para el
  dipolo de referencia a 14.150 MHz, AntSim/PyNEC obtuvo
  67.43 - j31.25 ohm (ROE 1.83) contra 67.4 - j31.3 ohm (ROE 1.84) de
  4nec2.
- Densidad de segmentación NEC uniforme (`lambda/160`) para la
  importación MMANA-GAL, seleccionada mediante un estudio reproducible
  de convergencia sobre 6 geometrías sintéticas (ver
  `docs/research/nec-segmentation-convergence.md` y ADR 0007).
- Pruebas de humo del ejecutable compilado (`scripts/build_windows.ps1`),
  en español e inglés, cubriendo diagnóstico, simulación, barridos,
  proyectos, exportación CSV/NEC, comparación con mediciones e
  importación MMANA-GAL.

## Reproducibilidad

- El ejecutable se genera con `scripts\build_windows.ps1` mediante
  PyInstaller, en modo `--onefile`.
- Build de referencia para el hash publicado: Python 3.13.15,
  PyInstaller 6.22.3, Windows 11 x64 (`AMD64`).
- No se afirma que dos ejecuciones de PyInstaller produzcan un
  ejecutable idéntico byte a byte; esta afirmación no fue verificada
  y no debe asumirse. El hash publicado identifica únicamente el
  ejecutable construido para este hito, no una garantía de
  reproducibilidad bit a bit del proceso de build.
